# 装机大师 · PC Builder Studio

> 把 DIY 装机变成零门槛的事——纯前端一站式装机工具

[在线体验](https://lwrnrt.github.io/pc-builder-studio) · [CloudStudio 预览](https://f4dca6edb619430898b10ec7142e5009.app.codebuddy.work)

---

## 功能

| 模块 | 说明 |
|---|---|
| **智能推荐** | 选择使用场景（可多选，如游戏+剪辑）+ 预算范围，自动生成 4 套分档方案，含完整清单、分项总价、性价比评级 |
| **组装中心** | 三栏工作台：左侧全品类配件库（品牌/价位筛选），中间主板插槽可视化拖拽装机，右侧实时兼容性检测 + 配置清单/总价 |
| **性能评估** | 百分制综合评分、各场景表现、游戏帧率实例（黑神话/赛博朋克等热门大作预估帧数）、视频渲染参考、功耗/散热/升级建议 |
| **保存分享** | 浏览器本地存储 + base64 链接一键分享，对方打开即还原配置 |

## 兼容性检测（9 条规则）

CPU-主板接口匹配 · DDR4/DDR5 内存类型 · 内存频率上限 · 散热器接口+压制能力 · 显卡长度 vs 机箱 · 散热器高度/冷排 vs 机箱 · 主板板型 vs 机箱 · 电源功率余量 · 核显/独显点亮检测

## 配件库（77+ 件）

Intel 12/13/14 代 + AMD AM4/AM5 处理器 · NVIDIA RTX 30/40 系 + AMD RX 7000 系 + Intel Arc 显卡 · DDR4/DDR5 内存 · NVMe/SATA 硬盘 · 风冷/水冷 · ITX~全塔机箱 · 80+铜牌~钛金电源

## 技术栈

纯 HTML/CSS/JS，零依赖，无框架，无构建。全部图标为内联 SVG，视觉用 Canvas 程序化生成（Hero 动画）。拖拽基于 Pointer Events 自实现。单页多文件架构，未压缩可直接阅读源码。

## 快速开始

```bash
# 直接用浏览器打开 index.html 即可，无需任何环境
open index.html

# 或部署到任意静态服务器
npx serve .
```

## 项目结构

```
pc-builder-studio/
├── index.html    # 页面结构与导航
├── styles.css    # 深色科技风设计系统
├── data.js       # 配件数据库（CPU/主板/显卡/内存/SSD/电源/散热/机箱/风扇）
├── engine.js     # 核心引擎（兼容性检测/推荐生成/性能评估/功耗估算）
├── icons.js      # 内联 SVG 图标
└── app.js        # 主应用逻辑（导航/推荐/选配/装机/性能报告/保存分享）
```
